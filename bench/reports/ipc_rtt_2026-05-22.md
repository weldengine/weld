## Analysis

- **p50 = 5 µs**, structurally below the 6 µs baseline. The E2 swap (legacy Wyhash → RTTI computeSchemaHash) is purely comptime — at runtime, the IPC makes no hash call on the hot path (the `schema_hash` value is baked into the binary). Any runtime difference is attributable to machine noise.
- **p99 and max also below baseline**: the run was particularly clean — no large syscall stalling the kernel scheduler.
- **stddev 3 µs**: dev-mode variance equivalent to the S6 cold-isolated baseline. The `socketpair()` loopback bench is local enough to resist most OS noise.

## Gate

**GO**. The E2/E6 non-regression gate (p50 ≤ 0.0063 ms — baseline +5 %) is met with margin.

## Post-swap S6 vs final E6 comparison

| Run | p50 | Verdict |
|---|---|---|
| E2 post-swap (5-run dev-mode) | median of medians 8 µs | NOISY — re-bench planned |
| E6 cold (1 clean dev-mode run) | **5 µs** | **GO** |

The previously archived E2 bench (median 8 µs) reflected a heavily loaded session (server build + Claude Code active). This E6 measurement, after partially freeing the session, returns to a sub-baseline plateau. Confirms the "comptime swap, runtime no-op" signature of E2.

## Conclusion

IPC RTT non-regression validated for the M0.2 tag. The GO verdict is robust: p50/p99/max all below the S6 cold-isolated baseline, despite dev-mode. The cold-isolated re-bench on an empty machine remains schedulable pre-tag for formalization, but the result should not deviate.
