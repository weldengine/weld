## Context

Second sub-milestone of M1.1 (Forge 3D rigid branch, comptime core arc M1.1.0–15). Delivers the first layer of the stratified pipeline: a dynamic multi-layer AABB tree (BVH) that produces the candidate pairs the narrowphase (M1.1.2–4) will consume. Algorithm scope is Jolt-inspired (dynamic BVH, insert/remove/update, overlap query, pair generation), structure is a Box2D-style incremental dynamic AABB tree — not a clone of either. The milestone also executes a one-time directory flatten: the `solvers_3d/` wrapper (a relic of the abandoned multi-solver era) is removed, and the shared pipeline gets its physical home at `forge_3d/pipeline/` per the updated `engine-directory-structure.md`.

## Scope

- **E0 — Directory flatten.** `git mv src/modules/forge/solvers_3d/forge_3d src/modules/forge/forge_3d`; delete the now-empty `solvers_3d/`; update the two `build.zig` references (root_source_file path at ~L138, comment at ~L312). No file content changes beyond `build.zig`. Full test suite stays green.
- **E1 — BVH core.** `Aabb(T).surfaceArea()` added to `src/foundation/math/aabb.zig` (with test). `src/modules/forge/forge_3d/pipeline/broadphase.zig` created with generic `Bvh(comptime T: type)`: index-based node pool (u32 indices, LIFO free-list, deterministic — same philosophy as `slot_alloc.zig` but internal, no generational packing), `insert(aabb, user_data) u32` (proxy id = node index), `remove(proxy)`, fat AABBs (margin from a `BroadphaseConfig` struct, default 0.1), SAH best-cost-child descent on insertion, rotation-based balancing, and a `validate()` invariant checker (parent/child link coherence, parent AABB contains children, height consistency) used by tests.
- **E2 — Update + query + determinism.** `update(proxy, tight_aabb) bool` with hysteresis (re-insert only when the tight AABB exits the stored fat AABB; return value = re-inserted). `queryAabb(aabb, collector)` overlap traversal with a visited-node counter exposed for the complexity test. Determinism test: two identical op sequences produce identical tree state and identical query results.
- **E3 — Multi-layer aggregate + pairs.** `BroadphaseLayer` enum (`static`, `dynamic`, `debris`, `trigger` — per `engine-physics-forge.md` §1.2), `Broadphase(comptime T: type)` owning one `Bvh(T)` per layer, per-layer moved-proxy tracking, a `const` default layer-pair matrix (see Notes), and `computePairs(gpa, out)` producing the candidate pair list: moved proxies tested against allowed layer trees, canonical `(min, max)` ordering on `user_data`, deterministic sort + adjacent dedup. No hash containers anywhere.
- **E4 — forge_3d integration + M1.1.0 gap fix.** `forge_3d` instantiates the pipeline at `Real` (re-exports in `root.zig`, test pins per `engine-zig-conventions.md` §13); tests pass at f32 and f64 (`-Dphysics_f64=true` local run). Fix the M1.1.0 gap: `Body` gains a `collision_layer: u8` field, `BodyManager.addBody` stores `desc.collision_layer` instead of dropping it, plus a safe getter and test. Integration test: N bodies created through `BodyManager`, world AABBs via `bodyAabb`, inserted into a `Broadphase(Real)` with `body_type`-derived layers (static→`.static`, dynamic/kinematic→`.dynamic`), packed `BodyId` as `user_data`; queries return the correct ids. `CLAUDE.md` updated per §3.4 (including the flattened paths from E0).

## Acceptance criteria

### Tests

- `src/foundation/math/aabb.zig` — `test "surfaceArea"` — exact value on a known box; zero-extent box → 0.
- `tests/broadphase_test.zig` — `test "insert N proxies keeps tree invariants"` — 1 000 deterministic pseudo-random AABBs (fixed seed), `validate()` green after every 100 inserts.
- `tests/broadphase_test.zig` — `test "remove restores invariants and free-list reuse is deterministic"` — interleaved insert/remove; freed node indices are reused LIFO.
- `tests/broadphase_test.zig` — `test "update hysteresis"` — displacement within the fat margin → no re-insert (returns false, tree untouched); displacement beyond → re-insert (returns true).
- `tests/broadphase_test.zig` — `test "queryAabb matches brute force"` — result set identical to an O(n) reference scan on 1 000 proxies, several query boxes, fixed seed.
- `tests/broadphase_test.zig` — `test "query cost is logarithmic"` — 10 000 unit boxes on a uniform grid; a single-cell query's visited-node counter ≤ 128 (generous c·log₂(n) bound; the plan's "Insert N AABB, query overlaps O(log n)" acceptance).
- `tests/broadphase_test.zig` — `test "identical op sequences produce identical trees and pairs"` — two instances fed the same sequence: byte-equal node arrays, identical pair lists.
- `tests/broadphase_test.zig` — `test "layer-pair matrix filters pairs"` — proxies across the 4 layers; only allowed layer combinations produce pairs (static×static never, trigger only vs dynamic, debris vs static/dynamic).
- `tests/broadphase_test.zig` — `test "computePairs matches brute force multi-layer"` — pair set identical to O(n²) reference with the same matrix, fixed seed; canonical ordering and no duplicates asserted.
- `tests/body_manager_test.zig` — `test "collision_layer is stored and retrievable"` — descriptor round-trip; stale handle → null.
- `tests/broadphase_test.zig` — `test "BodyManager to Broadphase integration"` — mixed static/dynamic bodies; layer derived from `body_type`; `queryAabb` returns exactly the expected `BodyId`s.
- f64 instantiation: full suite green under `-Dphysics_f64=true` (local run; CI stays on the default matrix).

## Notes

- **Dependency discipline.** `pipeline/broadphase.zig` imports `foundation` (math) only — never `weld_forge`, never `body*.zig`, never `config.zig`. The scalar arrives as the comptime parameter `T`; `forge_3d` instantiates at `config.Real`. `user_data` is an opaque `u32` to the tree; only the forge_3d side knows it is a packed `BodyId`. Body→layer mapping lives outside the pipeline (in tests for now; runtime wiring is a later milestone).
- **Why an incremental dynamic AABB tree and not Jolt's QuadTree.** Jolt's 4-wide batch-built tree targets massive parallel rebuilds; the plan's acceptance and the stratified pipeline call for incremental insert/remove/update with O(log n) queries. Box2D's `b2DynamicTree` (SAH descent + rotations + fat AABBs) is the proven shape for that — reimplemented against Weld conventions, not ported.
- **Default layer-pair matrix** (`const`, overridable later when `CollisionConfig` wiring lands — out of scope here): allowed = {dynamic×dynamic, dynamic×static, dynamic×debris, dynamic×trigger, debris×static}. Forbidden = {static×static, static×trigger, debris×debris, debris×trigger, trigger×trigger}.
- **Determinism by construction (anticipates M1.1.14).** No hash containers; node pool + LIFO free-list; tree shape is a pure function of the op sequence; pairs collected into an `ArrayList`, sorted by packed `u64` key `(@as(u64, min) << 32) | max` over `user_data`, adjacent-deduped. Fixed-seed `std.Random` PRNGs in tests only.
- **Fat AABB margin** is in world units (meters), default `0.1`, carried by `BroadphaseConfig` passed at `Bvh.init`. Velocity-based expansion is explicitly deferred (see Out of scope).
- **E0 is mechanical and first.** Zero literal `solvers_3d` paths exist in `src/` (verified by recon at `v0.11.0-forge-foundations`); only `build.zig` references the path. Historical `briefs/` are frozen artifacts — do not touch them.
- **Capsule AABB / conventions context.** World AABBs come from `BodyManager.worldAabb` (exact per primitive, delivered M1.1.0); the broadphase never recomputes shape AABBs.
- **Trap:** `Aabb(T).overlaps` is face-inclusive by design (touching faces count) — the brute-force reference tests must use the same convention (compare via `overlaps`, not hand-rolled strict inequalities).
