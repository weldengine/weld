## Context

Second sub-milestone of M1.1 (Forge 3D rigid branch, comptime core arc M1.1.0–15). Delivers the first layer of the stratified pipeline: a dynamic multi-layer AABB tree (BVH) that produces the candidate pairs the narrowphase (M1.1.2–4) will consume. Algorithm scope is Jolt-inspired (dynamic BVH, insert/remove/update, overlap query, pair generation), structure is a Box2D-style incremental dynamic AABB tree — not a clone of either. The milestone also executes a one-time directory flatten: the `solvers_3d/` wrapper (a relic of the abandoned multi-solver era) is removed, and the shared pipeline gets its physical home at `forge_3d/pipeline/` per the updated `engine-directory-structure.md`.

## Notes

- **Dependency discipline.** `pipeline/broadphase.zig` imports `foundation` (math) only — never `weld_forge`, never `body*.zig`, never `config.zig`. The scalar arrives as the comptime parameter `T`; `forge_3d` instantiates at `config.Real`. `user_data` is an opaque `u32` to the tree; only the forge_3d side knows it is a packed `BodyId`. Body→layer mapping lives outside the pipeline (in tests for now; runtime wiring is a later milestone).
- **Why an incremental dynamic AABB tree and not Jolt's QuadTree.** Jolt's 4-wide batch-built tree targets massive parallel rebuilds; the plan's acceptance and the stratified pipeline call for incremental insert/remove/update with O(log n) queries. Box2D's `b2DynamicTree` (SAH descent + rotations + fat AABBs) is the proven shape for that — reimplemented against Weld conventions, not ported.
- **Default layer-pair matrix** (`const`, overridable later when `CollisionConfig` wiring lands — out of scope here): allowed = {dynamic×dynamic, dynamic×static, dynamic×debris, dynamic×trigger, debris×static}. Forbidden = {static×static, static×trigger, debris×debris, debris×trigger, trigger×trigger}.
- **Determinism by construction (anticipates M1.1.14).** No hash containers; node pool + LIFO free-list; tree shape is a pure function of the op sequence; pairs collected into an `ArrayList`, sorted by packed `u64` key `(@as(u64, min) << 32) | max` over `user_data`, adjacent-deduped. Fixed-seed `std.Random` PRNGs in tests only.
- **Fat AABB margin** is in world units (meters), default `0.1`, carried by `BroadphaseConfig` passed at `Bvh.init`. Velocity-based expansion is explicitly deferred (see Out of scope).
- **E0 is mechanical and first.** Zero literal `solvers_3d` paths exist in `src/` (verified by recon at `v0.11.0-forge-foundations`); only `build.zig` references the path. Historical `briefs/` are frozen artifacts — do not touch them.
- **Capsule AABB / conventions context.** World AABBs come from `BodyManager.worldAabb` (exact per primitive, delivered M1.1.0); the broadphase never recomputes shape AABBs.
- **Trap:** `Aabb(T).overlaps` is face-inclusive by design (touching faces count) — the brute-force reference tests must use the same convention (compare via `overlaps`, not hand-rolled strict inequalities).
