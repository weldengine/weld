## Context

The `entity has T changed` per-tick change-detection mechanism was delivered by M0.8 (E3) and preserved unchanged by M1.0.0. This milestone does NOT reimplement it. It closes the test debt around that mechanism as exposed to the tree-walking interpreter: the single existing test proves only inter-archetype granularity, and a test-runner coverage gap (a M1.0.0 finding) means a class of `src/etch` inline tests — including the file where this milestone's tests live — may not execute under `zig build test`. The milestone's capability is a trustworthy, executed proof that a `changed` rule fires exactly on the entities modified this tick, down to the per-slot level inside one archetype.

**Scheduler livelock fix** (brought into scope via § Acted deviations — the windows-2025/ReleaseSafe CI hang this milestone surfaced):

- **Root cause — a data race on `Scheduler.shutdown`.** A non-atomic `bool`, written under `mu` at `deinit` but read **lock-free** in `workerMain`. In ReleaseSafe the optimizer can hoist that read, so a worker never observes `shutdown = true` → `deinit`'s `join()` blocks forever → the test's main thread hangs (the "failed to respond for 61 s" CI signature). Fixed: `shutdown` → `std.atomic.Value(bool)`, `.release` store + `.acquire` loads across all **5 access sites** (`16987cb`).
- **Permanent fail-fast watchdog** `tests/support/watchdog.zig`, wired into every test spec via `build.zig`'s `test_watchdog` module. Armed on the first line + `defer disarm()` (LIFO) so it covers `scheduler.deinit()`'s `join()` — the exact silent-hang site the dispatcher-spin watchdog does **not**. On a 5 s timeout: scheduler-state dump + `exit(2)`, never a 61 s build-runner kill. Applied to the **8 spawn/join tests** (`scheduler_test` ×2, `scheduler` ×3, `scheduler_dag` DAG test, `deque_test` concurrent-steal, `threading_test`). (`2c44d0a`)
- **Flake fix — `idle workers sleep`**: the timing-fragile one-shot `total_parks > 0` → a bounded dispatch→park retry loop that still **FAILS on zero parks observed** (no mask). (`2c44d0a`)
- **Watchdog clock amortized off the S1 spin** (`e7004e6`): S1 runs in ReleaseSafe, so the dispatcher-spin watchdog samples the wall-clock once per 65536 spins instead of every iteration.
